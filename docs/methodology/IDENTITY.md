# Identity resolution

A candidacy is keyed by election year, official constituency number and exact source name. These are not person identifiers. Similar names never cause automatic merges. The Biren Singh Heingang career is a reviewed exception supported by the Assembly's official member profile and election reports. All other cross-election matches require human review. Family contacts, bank accounts, personal addresses and voter-roll identifiers are deliberately omitted.

Original spellings survive in source_name. Display formatting never replaces raw records. District joins are versioned; old district names are not silently mapped to today's 16 districts.
