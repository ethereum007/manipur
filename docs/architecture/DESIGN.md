# Design foundation

Reading this as an editorial research publication for journalists, scholars and policy specialists, with cinematic cartography and an independent magazine aesthetic. Design variance 6, motion intensity 4, visual density 4. Native editorial CSS with Tailwind available; reusable accessible React components. Deep navy canvas, warm paper text, restrained gold editorial accent. Party colors are semantic data encoding, not branding.

The first review gate is the homepage, atlas and candidate profile in the actual Next.js App Router architecture. Responsive browser captures precede expansion. Motion uses IntersectionObserver and CSS with a reduced-motion alternative. Source notes and explicit unavailable states are part of the visual language.
